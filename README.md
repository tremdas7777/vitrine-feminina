# Vitrine Feminina

Loja de calçados femininos, bolsas e acessórios (projeto TanStack Start conectado ao Lovable).

Por enquanto a vitrine roda como site estático em `public/loja/` e a rota `/` redireciona para ela.
O checkout próprio (Pix), o painel `/admin` e as integrações estão sendo migrados para o app.

## Rodar localmente

```sh
npm i
npm run dev
```

## Atualizar o catálogo

```sh
sh tools/atualizar_catalogo.sh
```
